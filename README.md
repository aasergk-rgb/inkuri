# ABYSSAL DIGESTION（深淵の捕食生態系）

食物連鎖のバランス崩壊ギリギリを攻めるビオトープ型インクリメンタル。`index.html` をブラウザで開くだけで遊べます（単一ファイル・依存なし）。

## 仕組み
- 4段の食物連鎖（バクテリア → プランクトン → 小型魚 → チョウチンアンコウ）を Rosenzweig–MacArthur 型の捕食者–被食者方程式（Holling II型の捕食）でリアルタイムに数値積分。
- **富栄養化**で収容力を上げると産出は増えるが、「富栄養化のパラドックス」で振動が激化し、谷が絶滅ラインを割ると種が消える。
- 生産者の振幅が大きいほど **臨界ボーナス**、種の均等さが高いほど **多様性ボーナス**（シャノン指数）。
- **間引き**：ピーク時に個体群の30%を収穫。波を抑えつつエネルギーを得る。
- **突然変異ツリー**（5系統18種）：共食い・死骸高速分解・休眠胞子・頂点捕食者の解放など。⚠付きは高産出だが不安定化。
- **大絶滅**：化石遺伝子を得て、7つの異星環境（洞窟湖・氷衛星・メタンの海・超重力・硫酸雲・中性子星）へ。各環境で生態系の挙動が変わる。
- 数値表記は日本の命数法（万・億・兆…無量大数）。オフライン進行（最大8時間）・自動保存・エクスポート対応。

## 周回で解放されるコンテンツ
| 解放条件 | 機能 |
|---|---|
| 大絶滅 1回 | **環境イベント**（熱水噴火・鯨骨落下・冷水湧出・酸欠層・生物発光の宴・赤潮。観測でボーナス）／**自動化遺伝子**（自動再導入・自動間引き・自動環境強化・自動突然変異）／**環境適応**（各環境の記録で固有の永続ボーナス ★×3段階） |
| 大絶滅 2回 | **第5の種：ホネクイハナムシ**（死骸を食べる分解者。栄養循環と競合する）＋専用突然変異系統 |
| 大絶滅 3回 | **試練**（6種の制限付きラン。達成で永続報酬） |
| 累計化石遺伝子 300 | **彗星播種**（第二の転生。星の種で永続強化） |

## 実績と総合進捗
- 56個の実績。1つにつき全産出+5%。
- 「実績」タブで総合進捗（実績・到達環境・環境適応・試練・解放機能）と、次に解放される機能の一覧を確認できる。
